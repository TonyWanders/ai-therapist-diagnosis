A program that writes one funny diagnosis from an AI therapist to
`/output/entry.txt`, for the make.fun competition
[Your AI Therapist's Diagnosis](https://make.fun/bounty/u-motasimfuad-your-ai-therapist-s-diagnosis-4be14a41).

Run it with Python 3:

```
python3 main.py
```

It writes the line below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The line is 154 characters, inside the 1 to 200 gate.

## The line

```
Diagnosis: chronic validation-seeking. You ask an AI how you feel, then argue with the answer. That is progress: you used to argue with yourself for free.
```
